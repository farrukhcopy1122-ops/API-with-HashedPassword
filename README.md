A simple and secure authentication API built using Node.js, Express, and MongoDB.

This project handles user registration and login with hashed passwords, following a clean MVC structure, and is ready to connect with any frontend (EJS, React, Bootstrap, etc.).

Features

✅ User registration with validation

✅ Secure password hashing using bcryptjs

✅ Login authentication with proper error handling

✅ MongoDB & Mongoose for database modeling

✅ Express middleware for clean request handling

✅ Flash messages for success/error states (when using EJS frontend)

✅ Simple and extendable structure for JWT integration.
